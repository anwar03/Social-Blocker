# hand: ./install.sh detects your package manager and installs it for you.
# If you want to do it manually anyway:
#   Debian/Ubuntu:  sudo apt install python3-tk
#   Fedora:         sudo dnf install python3-tkinter
#   Arch:           sudo pacman -S tk
